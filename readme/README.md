# Simple To-Do List Web App

## Overview
A beginner-friendly web app built with Flask (Python) for managing tasks. Users can add and delete to-do items via a simple interface. Great for daily productivity!

## Features
- Add new tasks.
- View and delete tasks.
- Runs locally in a browser.

## Tech Stack
- Python with Flask.
- HTML/CSS for the frontend.

## How to Run
1. Install Flask: `pip install flask`
2. Run: `python app.py`
3. Open http://127.0.0.1:5000/ in your browser.

## Future Ideas
